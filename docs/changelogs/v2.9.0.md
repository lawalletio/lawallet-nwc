# v2.9.0

![LaWallet v2.9.0 — Native. Recoverable. Personal.](https://raw.githubusercontent.com/lawalletio/lawallet-nwc/main/docs/changelogs/assets/v2.9.0.png)

## Release date

2026-10-22

## Summary

This release gets LaWallet ready for **native wallets and card holders**. The
iOS and Android apps can now use an instance's passkeys and open its links,
users can delete their account from inside an app, and a lost key is no longer
the end of an account: the holder's **NFC card** can recover it at the
point of sale (#373). Operators can make a member's **first Lightning Address
free** (#372) and mint device tokens for themselves (#374).

The wallet remembers who you paid: Lightning Address sends show the
recipient's avatar, name and note in Activity, and one tap pays them again
(#375). Wallet errors are now translated to Spanish (#357, #358), and passkey
registration on Android takes one prompt instead of two (#355).

A second Sentry pass fixed the admin dashboard crash in the What's New dialog,
a timeout when refreshing many Nostr profiles, and 20-second waits on the
wallet balance (#378, #379). Payment and ledger failures that used to be only
logged now reach Sentry (#380). Everything runs on **Node 24.22.1**, which also
drops a compromised root certificate (#376).

## Heads-up before upgrading

### NIP-98 login only works from the configured `endpoint` (#364)

When the `endpoint` setting is filled in, Nostr (NIP-98) login is accepted only
from that exact origin. This closes a hole where a login signed for another
site could be replayed here. If you open your instance through a different
address, such as a LAN IP or `umbrel.local:<port>`, Nostr login fails with
`url tag invalid`. Use the configured URL, or clear `endpoint` on a
local-only install. Passkeys now bind to the page you are on instead of the
endpoint (#363).

### Unreachable wallets report a balance of 0 (#378)

`GET /api/remote-wallets/[id]/balance` used to return `503` when a wallet did
not answer. It now returns `200` with `balanceSats: 0`, and an archived (DEAD)
wallet answers without being dialed. A wallet that times out on the listener
is no longer retried over a direct relay connection, so the worst case drops
from about 20 seconds to the listener timeout.

### New optional variables for native apps (#365, #366)

| Variable                  | Purpose                                                                    |
| ------------------------- | -------------------------------------------------------------------------- |
| `APPLE_APP_IDS`           | Serves `apple-app-site-association` for iOS passkeys and links             |
| `ANDROID_APP_PACKAGE`     | Android package name, default `io.lawallet.wallet`                         |
| `ANDROID_APP_CERT_SHA256` | Signing-cert fingerprints for Android App Links and native passkey origins |

All are off when unset, so existing instances are unaffected. Only list a
fingerprint from a privately held signing key.
