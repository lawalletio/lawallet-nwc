# v2.2.0

## Release date

2026-07-30

## Summary

LaWallet NWC 2.2.0 lets a holder designate one card as their **MASTER
account-recovery card** and hardens the release pipeline against incomplete
deployment packages. The MASTER designation is enforced in the API and
PostgreSQL, follows the account rather than the physical card, and is visible
from the admin card list and detail page.

This release also closes the deployment-contract gap that allowed v2.1.0 to
publish before the Umbrel package supplied its required NWC vault key. Release
automation now checks the external Umbrel package before tagging or publishing
images.

## Highlights

### MASTER account-recovery card (#125)

- Admins and cardholders can set or remove a MASTER card from the card list or
  card detail page.
- Exactly one paired MASTER card is allowed per holder. Switching cards
  demotes the previous MASTER before promoting the new one, and the database
  enforces the invariant with a partial unique index.
- Activation, transfer, unpair, wipe, and rescue flows reset the designation
  to `SIMPLE`, so MASTER status never travels with the physical card.
- Admin and owner-scoped card endpoints expose the designation, with updated
  OpenAPI schemas and real-time card-list refreshes.
- This release ships the designation only. The recovery-share mechanism it
  prepares remains scheduled for Month 7.

### Deployment and release safety (#124)

- The release workflow now runs the deployment environment contract as a hard
  gate before version bump, tag creation, Docker publish, or package dispatch.
- The gate checks both the Umbrel app Compose file and its local regtest stack,
  requiring `NWC_VAULT_SECRET` on web and listener.
- Ordinary pull requests keep the external-package check advisory so unrelated
  work is not coupled to another repository, while a readable invalid package
  blocks releases.

## Upgrade notes

- The web image runs Prisma migration
  `20260730120000_add_card_master_unique` automatically. If a restored or
  hand-edited database already contains multiple paired MASTER cards for one
  holder, the newest is kept and the others are demoted to `SIMPLE`.
- No new runtime environment variable is introduced in v2.2.0.
  `NWC_VAULT_SECRET` remains a stable 32+ character secret shared by web and
  listener; back it up because rotating or losing it prevents decryption of
  stored NWC credentials.
- Docker and Umbrel packages use matching web/listener image versions. The
  bundled listener remains optional in the generic Docker Compose flow and is
  enabled with the `listener` profile.
