The SDK is real and lives in the monorepo: **`@lawallet/sdk`** (typed,
framework-free client — nostr-first NIP-98 auth, lightning-address
registration with payment, remote wallets/NWC, LUD-16, SSE) and
**`@lawallet/sdk/react`** (provider + hooks built on it).

The full documentation moved to its own section:

- [SDK Overview](/docs/sdk) — install, quickstart, endpoint coverage
- [Authentication](/docs/sdk/authentication) — signers and Nostr-signed requests
- [React Hooks](/docs/sdk/react) — the provider and every hook, with examples
- [Registration Flow](/docs/sdk/registration-flow) — the flagship onboarding + payment guide
- [NWC & Routing](/docs/sdk/nwc) — remote wallets and address modes

For a complete working app, see
[`example-onboarding`](https://github.com/lawalletio/sdk/tree/main/examples/example-onboarding)
in the repository.
